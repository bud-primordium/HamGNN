class HamGNN_v_1_0.models.utils.SSP(beta=1, threshold=20)[source]

Applies the element-wise Shifted SoftPlus (SSP) activation function.

The SSP formula is: \(\text{SSP}(x)=\text{Softplus}(x)-\text{Softplus}(0)\). This ensures that \(\text{SSP}(0)=0\).

Parameters:

  • beta – The \(\beta\) value in the Softplus formula. Defaults to 1.

  • threshold – When the input value is higher than this threshold, Softplus degenerates to a linear function. Defaults to 20.

Shape:

  • Input: \((N, *)\), where * means any number of additional dimensions.

  • Output: \((N, *)\), same shape as the input.
