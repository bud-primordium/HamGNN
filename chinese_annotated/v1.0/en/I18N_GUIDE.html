User Guide for HamGNN’s Multilingual Documentation System

Architecture Overview

The HamGNN documentation system now supports three-dimensional switching:

  • Branch: chinese_annotated, torchscript_export

  • Version: v1.0, v2.0

  • Language: zh (Chinese), en (English)

Multilingual Support Workflow

1. 生成翻译文件

# 激活环境
conda activate hamgnn-docs

# 生成 .pot 模板和 .po 文件
python generate_translations.py

This will create:

  • _build/gettext/*.pot - Translation template files

  • locale/en/LC_MESSAGES/*.po - English files to be translated

2. 翻译 .po 文件

Edit the locale/en/LC_MESSAGES/*.po files and fill in the translations:

msgid "原始中文文本"
msgstr "English translation"

Tip: You can use translation assistants or other tools for batch translation.

3. 构建多语言文档

# 构建所有版本和语言
python build_docs.py

# 仅测试英文构建
sphinx-build -b html -D language=en . _test_en

File Structure

docs/
├── locale/                 # 翻译文件
│   └── en/
│       └── LC_MESSAGES/
│           ├── source_v1/*.po
│           └── source_v2/*.po
├── _build/
│   ├── gettext/           # 翻译模板
│   └── all_docs/          # 构建输出
│       ├── chinese_annotated/
│       │   ├── v1.0/
│       │   │   ├── zh/
│       │   │   └── en/
│       │   └── v2.0/
│       │       ├── zh/
│       │       └── en/
│       └── torchscript_export/
│           └── ...

Configuration Description

versions.yaml

Defines the three-dimensional documentation structure, with each version supporting multiple languages:

branches:
  chinese_annotated:
    versions:
      v2.0:
        languages:
          - code: "zh"
            name: "中文"
          - code: "en"
            name: "English"

conf.py

Contains i18n configuration:

# 多语言支持配置
locale_dirs = ['locale/']   # 翻译文件目录
gettext_compact = False     # 每个文档生成单独的 .pot 文件

build_docs.py

Supports building based on the language parameter:

if language == "en":
    run_command(f"sphinx-build -b html -D language=en ...")

Maintenance Guide

  1. After adding new content: Rerun generate_translations.py to update the translation files

  2. To modify translations: Edit the .po files directly

  3. To test translation effects: Verify with the test build command

Automation Suggestions

In the future, we can:

  1. Use GitHub Actions to automatically detect untranslated content

  2. Integrate translation APIs to automatically translate new content

  3. Add translation progress tracking

Current Status

  • i18n framework has been set up

  • Supports switching between Chinese and English

  • All translation templates have been generated

  • Full translation is pending (can be assisted by translation tools)
