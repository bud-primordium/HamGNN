Graph Data Module

class HamGNN_v_1_0.GraphData.graph_data.graph_data_module(dataset=None, train_ratio=0.6, val_ratio=0.2, test_ratio=0.2, batch_size=300, val_batch_size=None, test_batch_size=None, split_file=None)[source]

Inherits from pl.LightningDataModule to manage graph datasets.

This class automates the loading, splitting, and batching of datasets, seamlessly integrating with the PyTorch Lightning training workflow.

setup(stage=None)[source]

Splits the dataset into training, validation, and test sets.

This method is part of the PyTorch Lightning workflow and is called at the beginning of training or testing. Its logic is as follows:

  1. If self.split_file exists, it loads predefined indices from this file to split the dataset. This ensures the reproducibility of experiments.

  2. If no split file is provided, the dataset is randomly split according to train_ratio, val_ratio, and test_ratio. The split is based on a fixed random seed (42) to ensure consistent results across runs.

  3. The logic executed depends on the stage parameter (‘fit’ or ‘test’).

Parameters:

stage (str, optional) – The current stage, automatically passed by Lightning. Can be ‘fit’, ‘test’, etc. Defaults to None.
