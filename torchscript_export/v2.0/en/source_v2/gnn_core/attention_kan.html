class HamGNN_v_2_0.models.HamGNN.Attention_kan.TensorExpansion(ham_type, nao_max)[source]

Bases: Module

Expand Hamiltonian or overlap matrices from atomic orbital basis sets to spherical harmonic basis sets.

The core operation of this module is to perform the following basis transformation, coupling atomic orbitals \(|l_i, m_i \rangle\) and \(|l_j, m_j \rangle\) into an irreducible representation of the total angular momentum \(|L, M \rangle\):

\[O_{LM} = \frac{1}{N} \sum_{m_i, m_j} C_{l_i m_i, l_j m_j}^{L M} \cdot H_{l_i m_i, l_j m_j}\]

where \(C\) are the Clebsch-Gordan coefficients.

This module can also handle atomic orbital ordering conventions from different DFT software (e.g., ‘openmx’, ‘siesta’, ‘abacus’) and convert them into a unified format of irreducible representations (irreps) compatible with the e3nn library.

ham_type

Type of Hamiltonian matrix (‘openmx’, ‘siesta’, ‘abacus’, ‘pasp’).

Type:

str

nao_max

Maximum number of atomic orbitals.

Type:

int

irreps_out

The output irreducible representations after expansion.

Type:

o3.Irreps

class HamGNN_v_2_0.models.HamGNN.Attention_kan.ClebschGordanCoefficients(max_l=8)[source]

Bases: Module

A module to precompute and store Clebsch-Gordan (CG) coefficients.

This module uses e3nn.o3.wigner_3j to compute Wigner 3j symbols and derives CG coefficients from them. The Wigner 3j symbols are related to the CG coefficients by:

\[\begin{split}\langle l_1 m_1, l_2 m_2 | l_3 m_3 \rangle = (-1)^{l_1 - l_2 + m_3} \sqrt{2l_3 + 1} \begin{pmatrix} l_1 & l_2 & l_3 \\ m_1 & m_2 & -m_3 \end{pmatrix}\end{split}\]

This version has been refactored for full JIT compatibility and backward compatibility with older models. All compatibility logic is encapsulated within this class, making it transparent to external code.

class HamGNN_v_2_0.models.HamGNN.Attention_kan.AttentionAggregation(num_heads, irreps_key, irreps_value, irreps_query)[source]

Bases: Module

An equivariant attention mechanism that processes key, value, and query vectors.

This module applies a scaled dot-product attention mechanism on the edges of a graph. The attention weight \(\alpha_{ij}\) is calculated as follows:

\[\alpha_{ij} = \frac{(Q_i \cdot K_j)}{\sqrt{d_k}}\]

where \(Q_i\) is the query vector of the destination node, \(K_j\) is the key vector of the source node, and \(d_k\) is the dimension of the key vector. The weights are then normalized using softmax and used to weight and aggregate the value vectors \(V_j\).
