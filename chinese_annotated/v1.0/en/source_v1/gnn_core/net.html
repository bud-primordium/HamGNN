Neural Network Module (net.py)

This module defines the core network architecture of HamGNN.

It mainly consists of three parts: 1. HamGNN_pre / HamGNN_pre2 / HamGNN_pre_charge: This series is the feature extraction network (or representation network),

responsible for learning O(3) equivariant feature representations from the input atomic structure (nodes, edges). They are based on the nequip framework and build node and edge features through multi-layer message passing (convolution).

  1. HamGNN_out: This is the output network, which receives equivariant features from the representation network and uses them to construct the equivariant Hamiltonian and Overlap Matrix.

  2. Auxiliary modules and classes: such as residual_block, Edge_builder, Triplet_builder, etc., which are the building blocks of the core network mentioned above.

class HamGNN_v_1_0.models.HamGNN.net.Edge_builder(irreps_in, irreps_out, invariant_layers=1, invariant_neurons=8, nonlinearity_scalars={'e': 'ssp'})[source]

Bases: GraphModuleMixin, Module

A module that builds edge features by combining node features and edge attributes.

The core idea of this module is to use a learnable Tensor Product to fuse geometric information (edge attributes represented by spherical harmonics) from the source node, target node, and the connection between them. The weights of the tensor product are not fixed but are dynamically generated by a fully connected network (FCN) based on the radial distance embedding of the edges. This allows the model to adjust the strength and form of interactions based on distance.

A variant of Edge_builder that uses the tensor product of two different node features.

This module applies linear transformations to the source and target node features separately and then computes their tensor product directly, instead of adding them first as in Edge_builder. This allows the model to learn more complex, asymmetric interactions. The resulting features are added to the existing edge features.

class HamGNN_v_1_0.models.HamGNN.net.Triplet_builder(irreps_in, irreps_out, invariant_layers=1, invariant_neurons=8, nonlinearity_scalars={'e': 'ssp'})[source]

Bases: GraphModuleMixin, Module

A module for constructing triplet (k-j-i) features.

This module aims to capture three-body interaction information between atoms. It creates triplet features by combining the features of two connected edges (k->j and j->i) through a tensor product. The weights of the tensor product are dynamically modulated by the angular embedding (calculated via spherical harmonics) formed by these three points.

This network is based on the nequip architecture. It learns rich, symmetry-aware feature representations from atomic structures (nodes, edges, angles) through a series of carefully designed embeddings and equivariant convolutional layers. Another variant of HamGNN_pre that adds support for charge doping.

class HamGNN_v_1_0.models.HamGNN.net.HamGNN_out(irreps_in_node=None, irreps_in_edge=None, irreps_in_triplet=None, nao_max=14, return_forces=False, create_graph=False, ham_type='openmx', ham_only=False, symmetrize=True, include_triplet=False, calculate_band_energy=False, num_k=8, k_path=None, band_num_control=None, soc_switch=True, nonlinearity_type='norm', export_reciprocal_values=False, add_H0=False, soc_basis='so3')[source]

Bases: Module

The output module of HamGNN, used to construct the Hamiltonian and overlap matrix from learned features.

This module is the core physical building block of HamGNN. It receives node and edge features generated by the representation network (e.g., HamGNN_pre) and then maps these features to local Hamiltonian and overlap matrix elements under the Symmetrized Atomic Orbitals (SAO) basis through several specialized networks (onsitenet, offsitenet).

The module has built-in compatibility with basis set definitions from various DFT software (OpenMX, SIESTA, ABACUS), can handle spin-orbit coupling (SOC), and can calculate band structures and atomic forces.

Calculate band structure including spin-orbit coupling (SOC).

This function handles Hamiltonians that include SOC effects, which are typically complex and non-diagonal (in spin space). It constructs the four spin components of the Hamiltonian (up-up, up-down, down-up, down-down) separately, combines them in reciprocal space, and finally solves the eigenvalue problem.

  • Hsoc_off_imag (torch.Tensor) – Real and imaginary parts of the off-site SOC Hamiltonian.
