HamGNN_v_2_0.models.utils.linear_bn_act(in_features, out_features, lbias=False, activation=None, use_batch_norm=False)[source]

Flexibly constructs a combined module of a linear layer, batch normalization, and an activation function based on input parameters.

This function constructs different combinations of modules depending on whether use_batch_norm and activation are provided.

Warning

The return type of this function is not fixed. When use_batch_norm is False and activation is None, it returns a standalone nn.Linear module; in all other cases, it returns an nn.Sequential container. The caller needs to be aware of and handle this difference.

Parameters:

  • in_features (int) – Input feature dimension of the linear layer.

  • out_features (int) – Output feature dimension of the linear layer.

  • lbias (bool, optional) – Whether the linear layer uses a bias. Defaults to False.

  • activation (Optional[Callable], optional) – The activation function instance to apply. If None, no activation function is added. Defaults to None.

  • use_batch_norm (bool, optional) – Whether to apply batch normalization before activation. Defaults to False.

Returns:

The assembled PyTorch module.

Return type:

Union[nn.Module, nn.Sequential]

HamGNN_v_2_0.models.utils.triplets(edge_index, num_nodes, cell_shift)[source]

Computes atomic triplets (k -> j -> i) from an edge list.

This function is crucial for building graph models that require three-body interactions (like bond angles). It first converts the edge list into a sparse adjacency matrix, and then, using the concept of adjacency matrix multiplication, efficiently finds all pairs of atoms (k, i) connected through an intermediate node j.

Parameters:

  • edge_index (torch.Tensor) – Edge index tensor of shape (2, N_edges), representing edges j -> i.

  • num_nodes (int) – Total number of nodes in the graph.

  • cell_shift (torch.Tensor) – Tensor of shape (N_edges, 3) representing the cell offset for each edge.

Returns:

A tuple containing triplet information: - col, row (torch.Tensor): The original edge indices. - idx_i, idx_j, idx_k (torch.Tensor): The atomic indices of i, j, k in the triplet. - idx_kj, idx_ji (torch.Tensor): The original edge indices of the two edges k->j and j->i that form the triplet.

Return type:

tuple

class HamGNN_v_2_0.models.utils.Expansion(irrep_in, irrep_out_1, irrep_out_2, internal_weights=False)[source]

An equivariant feature expansion module implemented using the e3nn library.

The core functionality of this module is to map an input feature (represented as an e3nn irreducible representation, irrep_in), through tensor product decomposition, to a 2D feature space formed by two other irreducible representations (irrep_out_1 and irrep_out_2). This is crucial when building interaction blocks in equivariant neural networks, as it allows information to be mixed and passed between tensor features of different orders.

For example, the interaction of a vector feature (1o) with another vector feature (1o) can produce scalar (0e), antisymmetric matrix/pseudovector (1o), and symmetric traceless matrix (2e) features. This module is the computational unit that implements this decomposition and mapping.

The core of the calculation utilizes the Wigner 3-j symbols (o3.wigner_3j), which describe how three angular momenta couple.

irrep_in

Irreducible representation of the input features.

Type:

o3.Irreps

irrep_out_1

Irreducible representation of the first dimension (rows) of the output features.

Type:

o3.Irreps

irrep_out_2

Irreducible representation of the second dimension (columns) of the output features.

Type:

o3.Irreps

internal_weights

Controls how weights are generated. If True, the weights are fixed nn.Parameter`s within the module; if `False, the weights are dynamically generated from the input features by an o3.Linear layer.

Type:

bool

forward(x_in)[source]

Parameters:

x_in (torch.Tensor) – Input feature tensor, whose dimensions should match irrep_in.

Returns:

Output 2D feature tensor, with shape (N_batch, irrep_out_1.dim, irrep_out_2.dim).

Return type:

torch.Tensor

get_expansion_path(irrep_in, irrep_out_1, irrep_out_2)[source]

Computes all possible decomposition paths from the input irrep to pairs of output irreps.

The condition for a path to exist is that ir_in must be contained in the tensor product of ir_out1 and ir_out2, according to group theory coupling rules.

Parameters:

  • irrep_in (o3.Irreps) – Input irreducible representation.

  • irrep_out_1 (o3.Irreps) – First output irreducible representation.

  • irrep_out_2 (o3.Irreps) – Second output irreducible representation.

Returns:

A list of instructions. Each instruction is a list with the format [input irrep index, output 1 irrep index, output 2 irrep index, whether weights are needed, 1.0, [multiplicities]].

Return type:

list

HamGNN_v_2_0.models.utils.upgrade_tensor_precision(tensor_dict)[source]

Upgrades the precision of specific types of tensors in a given dictionary.

This function iterates through a dictionary, converting torch.float32 tensors to torch.float64 (double), and torch.complex64 tensors to torch.complex128. All other types of tensors remain unchanged. The original device of the tensor is preserved during conversion.

Parameters:

tensor_dict (dict) – A dictionary containing PyTorch tensors.

Returns:

This function modifies the dictionary in-place.

Return type:

None

Notes

For float32 tensors, both .to(dtype=torch.float64) and .double() methods can be used to convert them to the float64 type. To maintain consistency with the conversion method for complex tensors, this function uses the .to() method.

Example

>>> data = {'float_tensor': torch.tensor([1.0, 2.0], dtype=torch.float32)}
>>> upgrade_tensor_precision(data)
>>> print(data['float_tensor'].dtype)
torch.float64
