模型顶层结构

class HamGNN_v_1_0.models.Model.Model(representation, output, losses, validation_metrics, lr=0.001, lr_decay=0.1, lr_patience=100, lr_monitor='training/total_loss', epsilon=1e-08, beta1=0.99, beta2=0.999, amsgrad=True, max_points_to_scatter=100000, post_processing=None)[源代码]

核心的 PyTorch Lightning 模型，用于封装和训练 GNN。

这个类集成了表示网络和输出网络，并定义了完整的训练、验证和测试循环。 它通过配置文件接收损失函数、评估指标和优化器参数，实现了高度的灵活性和可配置性。

representation

图表示网络，用于从输入图数据中提取特征。

Type:

nn.Module

output_module

输出网络，用于从表示网络提取的特征中预测目标属性。

Type:

nn.Module

losses

一个字典列表，定义了用于训练的损失函数。

Type:

List[Dict]

metrics

一个字典列表，定义了用于验证和测试的评估指标。

Type:

List[Dict]

post_processing

一个可选的后处理函数，用于在测试阶段计算需要梯度信息的物理量。

Type:

callable, optional

calculate_loss(batch, result, mode)[源代码]

根据 self.losses 配置计算总损失。

参数:

  • batch (dict) – 当前批次的数据，包含目标值。

  • result (dict) – 模型的预测输出。

  • mode (str) – 当前阶段的名称（’training’, ‘validation’, or ‘test’），用于日志记录。

返回:

计算得到的加权总损失。

返回类型:

torch.Tensor

执行单个验证步骤。

  • batch_idx (int) – 当前批次的索引。

返回:

validation_epoch_end(validation_step_outputs)[源代码]

在验证的每个 epoch 结束时调用。

该方法聚合所有验证批次的预测和目标，并生成散点图以可视化模型性能。

参数:

validation_step_outputs (List[dict]) – 从 validation_step 返回的输出列表。

返回:

在测试的每个 epoch 结束时调用。
