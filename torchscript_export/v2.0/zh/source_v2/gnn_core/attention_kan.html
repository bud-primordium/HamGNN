class HamGNN_v_2_0.models.HamGNN.Attention_kan.TensorExpansion(ham_type, nao_max)[源代码]

基类：Module

将哈密顿量或重叠矩阵从原子轨道基组展开为球谐函数基组。

该模块的核心操作是执行以下基组变换，将原子轨道 \(|l_i, m_i \rangle\) 和 \(|l_j, m_j \rangle\) 耦合为总角动量 \(|L, M \rangle\) 的不可约表示：

\[O_{LM} = \frac{1}{N} \sum_{m_i, m_j} C_{l_i m_i, l_j m_j}^{L M} \cdot H_{l_i m_i, l_j m_j}\]

其中 \(C\) 是 Clebsch-Gordan 系数。

该模块还能处理不同DFT软件（如 ‘openmx’, ‘siesta’, ‘abacus’）的原子轨道排序约定， 并将它们统一转换为 e3nn 库兼容的不可约表示 (irreps) 形式。

ham_type

哈密顿矩阵类型 (‘openmx’, ‘siesta’, ‘abacus’, ‘pasp’)。

Type:

str

nao_max

原子轨道的最大数量。

Type:

int

irreps_out

展开后的输出不可约表示。

Type:

o3.Irreps

forward(x)[源代码]

前向传播，将输入矩阵展开为球谐函数基组。

参数:

x (torch.Tensor) – 输入张量，形状为 (*, row.dim, col.dim)。

返回:

展开后的张量，其不可约表示由 self.irreps_out 定义。

返回类型:

torch.Tensor

class HamGNN_v_2_0.models.HamGNN.Attention_kan.ClebschGordanCoefficients(max_l=8)[源代码]

基类：Module

预计算和存储 Clebsch-Gordan (CG) 系数的模块。

该模块利用 e3nn.o3.wigner_3j 来计算 Wigner 3j 符号，并通过它们得到 CG 系数。 Wigner 3j 符号与 CG 系数通过以下关系相关联：

\[\begin{split}\langle l_1 m_1, l_2 m_2 | l_3 m_3 \rangle = (-1)^{l_1 - l_2 + m_3} \sqrt{2l_3 + 1} \begin{pmatrix} l_1 & l_2 & l_3 \\ m_1 & m_2 & -m_3 \end{pmatrix}\end{split}\]

此版本经过重构，以实现完整的JIT兼容性和新旧模型双向兼容。 所有兼容性逻辑都被封装在此类内部，对外部代码完全透明。

  • l2 (int) – 第二个角动量。

  • l3 (int) – 第三个角动量。

返回:

对应的 Clebsch-Gordan 系数张量。

torch.Tensor

class HamGNN_v_2_0.models.HamGNN.Attention_kan.AttentionAggregation(num_heads, irreps_key, irreps_value, irreps_query)[源代码]

基类：Module

处理键(key)、值(value)和查询(query)向量的等变注意力机制。

该模块在图的边上应用缩放点积注意力机制。注意力权重 \(\alpha_{ij}\) 的计算方式如下：

\[\alpha_{ij} = \frac{(Q_i \cdot K_j)}{\sqrt{d_k}}\]

其中 \(Q_i\) 是目标节点的查询向量，\(K_j\) 是源节点的键向量，\(d_k\) 是键向量的维度。 然后使用 softmax 对权重进行归一化，并用于加权聚合值向量 \(V_j\)。
